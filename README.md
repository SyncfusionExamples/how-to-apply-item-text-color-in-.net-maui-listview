# How to apply the item text color in .NET MAUI ListView (SfListView) ?

In [.NET MAUI ListView (SfListView)](https://www.syncfusion.com/maui-controls/maui-listview)<font face="Segoe UI"><span>,&nbsp;you can apply different text colors to elements within the <strong>ItemTemplate </strong>using the <strong>TextColor </strong>property combined with a converter. This approach allows dynamic color changes based on item properties.</span></font>
